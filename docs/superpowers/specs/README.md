# Design specs

Formal design documents for substantial changes live here.

## Naming

`YYYY-MM-DD-<short-topic>-design.md`

Example: `2026-05-03-harness-and-tooling-design.md`

## Flow

1. Brainstorm and agree on requirements.
2. Write or update a design file in this directory.
3. Review the spec (self-review + maintainer).
4. Add an implementation plan under `docs/superpowers/plans/` when ready to build.
