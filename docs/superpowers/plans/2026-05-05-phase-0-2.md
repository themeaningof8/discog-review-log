  "packageManager": "bun@<bun-version>",

- `pnpm` フィールド（`onlyBuiltDependencies`）: 削除（pnpm 固有設定）

### Task 5: scripts/install-git-hooks.mjs を更新する

> **学習ポイント:** `bun x <package>` は pnpm の `pnpm exec` に相当します。devDependencies にインストール済みのバイナリをプロセスを別途起動せずに実行できます。`process.execPath` を使うとスクリプトを実行している Bun バイナリのフルパスを取得できます。

**Files:**
- Modify: `scripts/install-git-hooks.mjs`

- [ ] **Step 1: scripts/install-git-hooks.mjs を以下の内容で置き換える**

```js
import { execFileSync } from "node:child_process";
import { existsSync } from "node:fs";

if (process.env.CI === "true" || process.env.CI === "1") {
  process.exit(0);
}

if (!existsSync(".git")) {
  process.exit(0);
}

execFileSync(process.execPath, ["x", "lefthook", "install"], { stdio: "inherit" });
```

`process.execPath` は現在スクリプトを実行している Bun バイナリのパスを返します。`bun x lefthook install` と同等ですが、PATH の Bun と実行中の Bun が一致することを保証できます。

- [ ] **Step 1: .github/workflows/ci.yml を以下の内容で置き換える**

`<bun-version>` は Task 3 でメモしたバージョンに置き換えること（例: `1.2.10`）。

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

concurrency:
  group: ci-${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

jobs:
  validate:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Bun
        uses: oven-sh/setup-bun@v2
        with:
          bun-version: "<bun-version>"

      - name: Install dependencies
        run: bun install --frozen-lockfile

      - name: Biome (CI)
        run: bun run check:ci

      - name: Typecheck
        run: bun run typecheck

      - name: Test
        run: bun run test

      - name: Knip
        run: bun run knip
```
